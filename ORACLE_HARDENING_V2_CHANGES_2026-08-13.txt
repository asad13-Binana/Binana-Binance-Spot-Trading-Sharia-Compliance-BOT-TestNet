BINANA ORACLE HARDENING V2 - LOCAL REVIEW CHANGE LOG
Date: 2026-08-13
Publication state: SOURCE MAY BE PUBLISHED; NOT DEPLOYED

Purpose
Infrastructure/deployment/security hardening only. Strategy signals, indicators,
position/risk calculations, execution decisions, Sharia rules/decisions, pair
selection, promotion gates, and package safety interlocks remain frozen.

Major changes
1. Replaced Ubuntu docker.io bootstrap with Docker CE from Docker's official
   signed Ubuntu repository; ARM64/Ubuntu 24.04/Python 3.12/resource checks.
2. Removed permanent Docker-group access from deployment, monitoring and bot
   identities; added a root-owned constrained deployment wrapper.
3. Made /etc/binana-freqtrade-v101/.env root:root 0600 and replaced shell
   sourcing with strict literal-data parsing, symlink/TOCTOU/owner/mode checks.
4. Added explicit immutable artifact SHA-256 owner approval before deployment.
5. Added separate BINANA namespace, paths, systemd units, lock, logs, database,
   backup root, Compose project and monitor identity.
6. Added BOT_PRODUCT, BOT_ENVIRONMENT and BOT_INSTANCE_ID to runtime,
   monitoring and Telegram output without altering trading logic.
7. Added Docker live-restore/log bounds, pids limits, dropped capabilities,
   no-new-privileges, internal control network and zero public Compose ports.
8. Added Docker ingress and OCI metadata firewall guard without blocking OCI
   DNS, NTP or volume traffic.
9. Added bounded Chrony/OCI NTP synchronisation plus a 100-ms last-offset gate,
   4-GiB swap headroom with existing-swap filesystem/owner/mode validation, swappiness 10,
   Ubuntu-only unattended security upgrades, no automatic reboot, and manual
   exact-version Docker upgrades.
10. Added loopback monitor port collision detection, maintained monitor-only
    credentials and no Docker socket/sudo/trading credentials for botmon.
11. Added secretless Oracle diagnostics including 10-request Binance HTTPS
    DNS/TCP/TLS/TTFB/total min/median/p95/max benchmark.
12. Added disk-pressure monitoring with an authenticated critical pause-new-
    entries action, bounded journald/Docker logs, Python SQLite online backups,
    traversal-safe SHA-256 snapshot manifests and non-mutating restore checks.
13. Added fail-safe SSH hardening with authorized-key precheck, sshd -t,
    rollback and reload only after validation.
14. Added infrastructure/security regression tests and regenerated exact audit
    ledgers. Release manifest regeneration is performed only after all files and
    reports are complete.
15. Fixed deployment pause/reconcile generation to use HMAC-authenticated
    deploy-installer envelopes bound to the currently installed release hash.
16. Fixed privileged-script path/UID override, legacy-stack collision, symlink,
    artifact staging TOCTOU, backup special-file and SSH-target edge cases.
17. Fixed the GitHub integration fixture to override the production Oracle
    `SHARED_HOST_PATH` with the checked-out `./shared` tree. This preserves
    production paths while providing Sharia fixtures and runner-owned audit
    state during container simulation.
